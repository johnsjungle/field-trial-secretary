# Trial Setup Source Notes

This app starts trial setup with the fields most likely to be needed before entries, scoring, and result reports can work.

## ASFA Sources Checked

ASFA public site:

- Trial Date Request
- Trial Forms
- Entry Forms
- Rule Book / Policies
- Hound Records
- Judges

ASFA Trial Date Request fields that informed the app:

- Club initials
- Club
- Requestor name
- Requestor address
- Email
- Phone
- Action: request, change, cancellation
- Trial date
- Trial location
- Region held
- Trial type: All-Breed, Specialty, Invitational, Fun Trial, National Breed Specialty
- Breed for specialty events
- Singles offered
- LCI offered
- Priority date

ASFA Trial Forms page confirms related workflow outputs:

- Sample premiums
- 45-day schedule
- Field Trial Secretary report
- ASFA point system
- Draw order
- Hound certification form
- Judging form
- Protest form
- Record sheet
- Electronic submission of records

## AKC Sources Checked

AKC Lure Coursing public site:

- Lure Coursing overview
- Club resources
- Regulations/resources
- Event forms
- Secretary report reference
- Online event management system
- Judges directory/resources

AKC notes that informed the app:

- Clubs may submit result copies and the Secretary Report in PDF format.
- Lure coursing event setup needs club, event, dates, eligible breeds/classes, judges/resources, and secretary reporting.
- AKC event management may remain a later export/integration target.

## App Decisions

Version one should capture:

- Association
- Club
- Trial name
- Event or sanction number
- Trial type
- Specialty breed when applicable
- Region
- Dates
- Site and nearest major city
- Closing date/time
- Roll call, inspection, and first course times
- Secretary, chair, and huntmaster
- Singles/LCI/priority flags
- Active trial selection

The app should allow multiple trials to be prepared at the same time, with one clearly marked active trial.
