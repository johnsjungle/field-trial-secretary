# Field Trial Secretary v0.4.2 beta

Improves printed trial-day paperwork and adds in-app guidance.

- Adds compact, expandable help throughout the application and a searchable problems and issues section in the Trial Guide.
- Adds roll-call print choices for combined entries, individual fields, lanes, and field/lane combinations.
- Adds running-order, breed/class, call-name, registered-name, class, entry-number, and lane sorting with standard, quick, and detailed formats.
- Separates draw sheets by field so each page contains only that field's courses.
- Separates preliminary, finals, and runoff judge-sheet packets by field and prints a clear field heading on draw, judge, and record sheets.
- Preserves field assignments when creating combined runoff draw and judge packets.
- Prevents AKC PDF form values from carrying between breeds or BIE packet pages.
- Fits AKC call names with breed abbreviations inside the available scoresheet space.

Retains the verified application updater and the signed, notarized macOS release workflow.
