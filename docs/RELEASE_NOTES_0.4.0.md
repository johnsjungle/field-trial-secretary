# Field Trial Secretary v0.4.0 beta

This release adds application updating under Admin > Updates & Versions.

- Check the public release list and download Windows, Apple Silicon, or Intel installers.
- Packaged installations can prepare verified updates and select Install and Restart.
- Downloads are checked against SHA-256 checksums. Mac updates also require Developer ID verification.
- The updater backs up SQLite and replaces program components only, preserving trial data.
- Startup is verified; failed startup restores the previous program.
- Source installations retain manual download links. Offline trial work remains available.

Includes all v0.3.10 trial features. Install v0.4.0 manually once to gain the built-in updater for subsequent releases. Existing v0.3.10 installers are retained as historical releases.
