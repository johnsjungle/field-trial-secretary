# Best in Event setup

On BIF / BIE choose **BIE — Best in Event**. The active trial stores the event configuration, draw, and scores.

1. Select a source trial day and choose **Add This Day’s BOB Winners**. Repeat for each day.
2. To include another qualifier, select that day, choose a hound, and click **Add Selected Hound**. The picker sorts by breed and daily combined score and identifies BOB winners. Eligibility and any multi-day points calculation remain the secretary’s decision.
3. Mark the entrants **Running BIE**, assign judges, and draw. Existing manual course and blanket editing remains available.
4. Print the event draw and judge sheets. ASFA judge sheets mark BIE.

Imported entrants are snapshots with source trial and entry identifiers. Adding the same breed/registration twice keeps one entrant (registered name is the fallback). Review unidentified hounds manually. Source-day trial entries and scores are not modified. If source results change, remove and re-add the affected entrant to refresh its snapshot.

Changes to an existing event draw require confirmation and clear its scores and tie runoffs. Cancel preserves the posted draw. Switching event type clears runner selections. Adding/removing candidates retains selections for remaining candidates.

## Course configuration

Choose Dogs per course: automatic, two-dog elimination pairs, three maximum, or individual runs. Enable Keep like breeds together to draw each breed separately. Odd entrants remain in solo courses for secretary review; no automatic byes or winner advancement are applied. These settings configure the current draw. Optional elimination mode adds advancement and saved round history.

Add Empty BIE Course preserves existing assignments and scores and opens the manual editor. Use Move to to assign hounds. Moves enforce the maximum and require confirmation because colors may change and event scores/tie runoffs are cleared. Manual moves may override breed grouping. Changing setup after drawing requires confirmation and a fresh draw.

## Manual setup and optional elimination

Standard BIE remains the default. Mark runners and click Set Up BIE Manually to start with an empty course without randomizing. Add courses and assign every runner using the course selectors. Assign judges and Finish Manual Setup before scoring or printing.

Enable Use elimination rounds only for elimination events. Select the winner of each course, including explicit byes, then Advance Winners. Winners may enter a random draw or a manual next-round setup. Each advance saves the completed draw, judges, scores, colors, and advancing hounds in Previous round history. History is read-only and saved with the trial. Twelve dogs in pairs produce six courses, then three courses, then one three-dog final; use manual setup for different arrangements. Confirm BIE Winner completes the last course. Changing a current score clears that course's winner selection for review.
