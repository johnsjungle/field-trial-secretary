# HALO v0.5.1

Corrects AKC specialty draw-sheet order and improves AKC scoresheet alignment.

- Prints AKC specialty stakes in Open, Specials, Veteran order.
- Recognizes Special, Specials, Field Champion, FCH, and FC as the same AKC print-order position.
- Applies the corrected order to both the on-screen preview and generated draw-sheet PDF.
- Reorders only the printed presentation; existing entries, course assignments, blanket colors, judges, and scores remain unchanged.
- Centers AKC record-sheet placements in their column and increases them to 11-point type.
- Moves the Field Trial Chairman name right so it clears the printed signature label.
- Keeps Windows portable, Ubuntu AppImage and Debian, and signed and notarized Apple Silicon and Intel macOS installers in the same release.

Existing installations can install this release from **Admin > Updates & Versions**. HALO backs up the database, replaces program files, and restarts while preserving trial data.
