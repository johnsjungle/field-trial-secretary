# HALO v0.5.5

Adds controlled mixed-breed pairing for Kennel and Breeder specialty stakes.

- Adds an **Allow mixed-breed Kennel and Breeder pairs** setting to each trial.
- Enables mixed-breed pairing by default for International Invitational trials.
- Keeps same-breed pairing as the default for other trial types unless the secretary enables the option.
- Allows two different breeds to form a pair when both hounds are marked for the selected specialty stake.
- Shows both full breed names on specialty reports for a mixed pair.
- Ranks all Kennel or Breeder pairs together when mixed-breed pairing is enabled.
- Keeps the one-Kennel-pair and one-Breeder-pair limit for each hound.
- Retains direct reassignment of hounds that are already paired.
- Includes Windows portable, Ubuntu AppImage and Debian, and signed and notarized Apple Silicon and Intel macOS installers.

Existing installations can install this release from **Admin > Updates & Versions**. HALO backs up the database, replaces program files, and restarts while preserving trial data.
