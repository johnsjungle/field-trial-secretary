# HALO v0.5.3

Adds multi-trial owner reporting and accurate preliminary and finals judges maps.

- Adds an **Owner List** under **Admin Tools > Reports** using any selected trials.
- Counts one owner across multiple hounds and trials and lists unique hounds, entries, contact information, and trials.
- Adds an adjustable 70–100% owner-name similarity setting and shows the spellings HALO grouped together for review.
- Lists entries with a missing owner separately so they can be corrected.
- Builds the **Preliminary Judges Map** from the saved draw, preserving split stake flights and their actual course sizes.
- Adds a **Finals Judges Map** built from the saved final draw, excluding hounds that cannot run and respecting field assignments.
- Shows both the number of runs and the size of every course on preliminary and finals judges maps.
- Orders stakes as Open, Field Champion/Special/Excellent, then Veteran, with split flights A and B in order.
- Includes Windows portable, Ubuntu AppImage and Debian, and signed and notarized Apple Silicon and Intel macOS installers.

Existing installations can install this release from **Admin > Updates & Versions**. HALO backs up the database, replaces program files, and restarts while preserving trial data.
