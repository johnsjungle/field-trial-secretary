# HALO v0.5.4

Improves Breeder and Kennel specialty-pair setup when a requested hound is already assigned to another pair.

- Keeps already-paired hounds visible in the partner list.
- Shows the hound's current partner beside its name.
- Allows the secretary to reassign that hound after a clear confirmation.
- Removes both previous partner links before saving the requested pair, preventing one-sided or stale pairings.
- Keeps Breeder and Kennel pair assignments independent.
- Continues to require two different, same-breed hounds that are both marked for the selected specialty stake.
- Includes Windows portable, Ubuntu AppImage and Debian, and signed and notarized Apple Silicon and Intel macOS installers.

Existing installations can install this release from **Admin > Updates & Versions**. HALO backs up the database, replaces program files, and restarts while preserving trial data.
