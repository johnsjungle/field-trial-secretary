# Specialty stakes

On Entries, mark each hound for Kennel, Breeder, or Bench and save the entry. The Specialty Stakes panel appears below the entry list. Choose a partner separately for Kennel and Breeder. Both hounds must be entered in that specialty stake and be the same breed, but may run in different regular stakes. Each hound has one partner per specialty stake. Unpair a hound before using it in another pair. Selections save automatically and do not change draw separation.

The report name fields allow a shared breeder or owner/kennel name. When left blank, reports use the entries' breeder or owner information. The existing Bench checkbox represents individual Dual Champion entries. Specialty reports always label these entries Dual Champion Stake. Championship eligibility is not automatically checked.

Under Admin > Catalog, select the trial dates and click Build Specialty Stakes Catalog. Each trial lists individual entries followed by numbered Breeder and Kennel pairs. Missing partners are marked for correction. Numbers are assigned in call-name order for each report, so finalize entries and pairings before distributing the catalog.

Under Main Results, Print Specialty Stakes Results appears below the ribbon report when at least one specialty entry is marked. It shows each hound's preliminary and final score, combined pair totals, and rankings within each breed. Runoff, BOB, and BIF scores are excluded. Ties share a rank; missing scores, invalid pairs, and recorded non-scoring outcomes receive no rank. Rankings remain provisional while entries are incomplete. These are score tabulations, not automatic eligibility decisions.

The new PDF endpoints require the updated local server. Restart the source application and refresh the browser after installing the source changes. Existing portable/Mac packages need a new build to include this feature.
