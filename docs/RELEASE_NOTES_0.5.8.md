# HALO v0.5.8

Highlights entry and draw mismatches before a trial runs in the wrong stakes or leaves late entries out of its draw.

- Turns the Trial Guide pink and places a warning first when entries change after the running order was updated, a hound's stake differs from the draw, or a late entry is missing from the draw.
- Names affected hounds and explains how to review entries, roll call, and Running Order & Assignments.
- Adds a review popup before building preliminary draws. An outdated running order directs the user to **Update Hound Entries** first. An unscored draw can then be rebuilt from the reviewed current entries.
- Once preliminary scoring has started, directs stake corrections to **Finals Stake** and preserves the scored preliminary draw.
- Recognizes explicit finals-stake corrections, mixed stakes, champion stake aliases, and hounds that are absent or otherwise not running.
- Includes the previous Windows release's corrected Results grouping, combined totals, placements, ASFA record sheets, and startup fixes for macOS and Ubuntu users as well.

Available for Windows, Apple Silicon Mac, Intel Mac, and Ubuntu (AppImage and Debian package). Mac installers use Developer ID signing and Apple notarization.

Existing installations can update from **Admin > Updates & Versions**. HALO backs up and preserves trial data while replacing program files and restarting. New installations contain a blank starter database template and no live trial database.
