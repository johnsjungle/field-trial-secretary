    Prelim Scoring

    Enter judge sheet totals by run group, course, and blanket color. Record excusals, dismissals, and DQs here too.

    Marking prelims complete locks preliminary scores so finals draws and posting sheets are not changed by accident. Unlock prelims only when correcting an error.

    Finals Scoring

    Build finals draws and enter finals scores by run group after preliminary scoring is complete.

    Lock finals once a stake or breed has been checked and posted. Unlock only when correcting a score.

    ASFA Record Packet

    Create the complete end-of-trial ASFA record packet with all record sheets in order.

    The record packet uses completed results, ASFA record and entry-form alignment settings, splits large stakes across multiple record sheets, includes refund/per-capita handling, and inserts first-time entry forms before uploaded certificates.

    ASFA Secretary Report

    Build the ASFA Field Trial Secretary report for trial submission.

    The report also fills club, region, chair, secretary email, trial date, location, entry counts, and calculated ASFA fees from the active trial.
